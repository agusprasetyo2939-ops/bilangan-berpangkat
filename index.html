Bilangan berpangkat adalah perkalian berulang dari suatu bilangan yang sama.

Bentuk Umum:

$$a^n = \underbrace{a \times a \times a \times \dots \times a}_{\text{sebanyak } n \text{ faktor}}$$

  • $a$ = bilangan pokok / basis
  • $n$ = pangkat / eksponen

Contoh:

$2^4 = 2 \times 2 \times 2 \times 2 = 16$

$5^3 = 5 \times 5 \times 5 = 125$

Ingat!

$3^4 \neq 3 \times 4$

Tetapi:

$3^4 = 3 \times 3 \times 3 \times 3 = 81$

Jika basisnya sama, pada operasi perkalian pangkatnya dijumlahkan:

$$a^m \times a^n = a^{m+n}$$

Contoh Standar:

$2^3 \times 2^4 = 2^{3+4} = 2^7 = 128$

$3^2 \times 3^5 = 3^{2+5} = 3^7 = 2187$

Tipe Soal TKA:

$2^5 \times 2^3 = ?$

Jawab: $2^{5+3} = 2^8 = 256$

Jika basisnya sama, pada operasi pembagian pangkatnya dikurangi:

$$\frac{a^m}{a^n} = a^{m-n} \quad \text{dengan } a \neq 0$$

Contoh:

$$\frac{5^7}{5^3} = 5^{7-3} = 5^4$$

Jadi: $5^4 = 625$

Jika suatu bilangan berpangkat dipangkatkan lagi, maka pangkatnya dikalikan:

$$(a^m)^n = a^{m \times n}$$

Contoh:

$$(2^3)^4 = 2^{3 \times 4} = 2^{12} = 4096$$

Perhatikan: pangkat dikalikan, bukan dijumlahkan.

E. Pangkat pada Perkalian

$$(a \times b)^n = a^n \times b^n$$

Contoh: $(2 \times 3)^4 = 2^4 \times 3^4 = 16 \times 81 = 1296$

F. Pangkat pada Pecahan

$$\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}$$

Contoh: $$\left(\frac{2}{3}\right)^3 = \frac{2^3}{3^3} = \frac{8}{27}$$

Untuk $a \neq 0$, setiap bilangan berpangkat $0$ nilainya adalah $1$:

$$a^0 = 1$$

Contoh: $5^0 = 1$, $1000^0 = 1$, $(-7)^0 = 1$

Jebakan TKA ⚠️

Jangan menganggap $a^0 = 0$. Yang benar: $a^0 = 1$ selama $a \neq 0$.

Pangkat negatif dapat diubah menjadi bentuk pecahan bernilai positif:

$$a^{-n} = \frac{1}{a^n}$$

Contoh Dasar:

$2^{-3} = \frac{1}{2^3} = \frac{1}{8}$

$5^{-2} = \frac{1}{5^2} = \frac{1}{25}$

Jika berbentuk pecahan:

$$\left(\frac{2}{3}\right)^{-2} = \left(\frac{3}{2}\right)^2 = \frac{9}{4}$$

⚡ Trik cepat: Pangkat negatif → balik pecahan → pangkat menjadi positif.

Pangkat pecahan berkaitan langsung dengan bentuk akar:

Pangkat Pecahan $1/n$

$$a^{\frac{1}{n}} = \sqrt[n]{a}$$

$16^{\frac{1}{2}} = \sqrt{16} = 4$

$27^{\frac{1}{3}} = \sqrt[3]{27} = 3$

Pangkat Pecahan $m/n$

$$a^{\frac{m}{n}} = \sqrt[n]{a^m}$$

$8^{\frac{2}{3}} = \sqrt[3]{8^2} = \sqrt[3]{64} = 4$

Ini sangat penting untuk TKA karena sering digunakan untuk menyederhanakan perhitungan.

$(-2)^4 = 16$

Hasilnya selalu positif.

2. Pangkat Ganjil

$(-2)^3 = -8$

Hasilnya tetap negatif.

Hati-hati dengan tanda kurung!

$(-2)^4 = 16$ tetapi $-2^4 = -16$

Karena pada $-2^4$, tanda negatif bukan bagian dari bilangan yang dipangkatkan.

TKA dapat meminta kita menentukan bilangan mana yang lebih besar.

Contoh 1: Mana yang lebih besar? $2^{10}$ dan $4^5$

Ubah $4$ menjadi $2^2$:

$4^5 = (2^2)^5 = 2^{10}$

Jadi: $2^{10} = 4^5$

Contoh Lebih Menantang: Manakah yang lebih besar? $3^8$ atau $9^4$

Karena $9 = 3^2$, maka:

$9^4 = (3^2)^4 = 3^8$

Jadi keduanya sama besar ($3^8 = 9^4$).

Bilangan yang sangat besar atau sangat kecil dapat ditulis dalam bentuk:

$$a \times 10^n \quad \text{dengan } 1 \le a < 10$$

Strategi Cepat Menghadapi Soal TKA

Metode penyelesaian efisien untuk menghemat waktu saat ujian (Sesuai Dokumen Bagian N).

Strategi 1 — Samakan Basis

Jika menemukan bilangan dengan basis berbeda seperti $4^5$, $8^3$, $16^2$, segera ubah menjadi basis prima terkecil (misal basis 2):

4⁵ = (2²)⁵ = 2¹⁰

8³ = (2³)³ = 2⁹

16² = (2⁴)² = 2⁸

Urutan dengan mudah: 2¹⁰ > 2⁹ > 2⁸ (4⁵ > 8³ > 16²)

Strategi 2 — Jangan Langsung Hitung Angka Besar

Misalnya terdapat bentuk:

$$\frac{2^{20} \times 2^5}{2^{10}}$$

Tidak perlu menghitung nilai $2^{20}$. Gunakan langsung sifat penjumlahan dan pengurangan pangkat:

$2^{20+5-10} = 2^{15}$

Strategi 3 — Cari Pola / Faktorkan

Contoh penjumlahan berulang: $2^2 + 2^3 + 2^4$. Faktorkan berpangkat terkecil $2^2$:

2²(1 + 2 + 4) = 4 × 7 = 28

Trik faktorisasi sangat efektif menghancurkan soal penjumlahan berpangkat!
